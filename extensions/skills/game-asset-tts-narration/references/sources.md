# 获取来源

上游是可选或必要资源的获取入口；本包没有打包权重、第三方模型、插件或他人技能。标为未复核的链接是来源记录，不冒充本次可达验证。

| 来源 | 用途与边界 | 核对 |
|---|---|---|
| [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS) | VoiceDesign 的公开上游；用虚构音色可替代项目私有语音工作台。 | 2026-10-18 已打开上游页面 |
| [Qwen VoiceDesign 权重](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign) | 取得模型与 tokenizer，放 TTS_MODELS_DIR 对应目录或按上游配置。 | 2026-10-18 已打开上游页面 |
| [Fish Speech](https://github.com/fishaudio/fish-speech) | 公开 TTS 项目，具体代码和模型许可分别以所选版本为准；不附原语音工作台。 | 2026-10-18 已打开上游页面 |
| [Fish S2 Pro 权重](https://huggingface.co/fishaudio/s2-pro) | 模型卡与 Fish 服务端安装/硬件/许可说明；本包只附调用器。 | 2026-10-18 已打开上游页面 |
| [SenseVoiceSmall](https://huggingface.co/FunAudioLLM/SenseVoiceSmall) | 中文识别质检模型；TTS_ASR_MODEL 指向本地模型。 | 2026-10-18 已打开上游页面 |
| [Breeze TTS 2](https://github.com/breezeblue-ai/breeze-tts) | 可选声音指令与设计方案；不复制原项目表演台本或模型。 | 2026-10-18 已打开上游页面 |
| [Breeze 模型卡](https://huggingface.co/BreezeBlue/Breeze-TTS-2) | 按模型卡部署，中文表现与参数需按普通讲解另测。 | 2026-10-18 已打开上游页面 |
| [FFmpeg](https://ffmpeg.org/documentation.html) | 抽帧、色键、滤镜、编码与完整解码；按自己的平台安装。 | 2026-10-18 已打开上游页面 |
