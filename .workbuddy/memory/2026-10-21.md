## 分析 zeroa234/game-asset-aesthetic-test 的 Spine 三个技能包
- 目标：用户想复现网友的 Agent 美术工作流，聚焦 game-asset-spine-cutout / -portrait / -multiview。
- 结论：三条路线有依赖关系与成本差。cutout 零 GPU 可做（脚本自带 setup_pose.png、每动作 GIF、_sheet.png 接触表作离线验收）；portrait 需 ComfyUI + See-through + DWPose + 超分；multiview = portrait 拆层 ×3 + 三视图生成 + three.js 演示，最后做。
- 关键代码事实：spine-cutout-rig.py 只读 part_00/01/02/04，远侧手脚复用同图并压暗 c8c0c8ff；几何常量写死为测试角色（ELBOW_Y=150, KNEE_Y=50, THIGH_LEN=180, BELT=124, 总高约 621px, 枢轴表 P）。front-rig.py 则从 DWPose + 层包围盒推骨骼，更可移植。
- 关键验收指标：seethrough-to-layers.py 打印 recomposite（mean_abs_err_fg ≲12/255、alpha_miss <1%）；spine-verify.mjs 无 MISSING；三视图同身高 ±0.5%。
- 本机环境实测：node 22.22.2 / python 3.13.12 有；ffmpeg、Blender、Spine 编辑器、ComfyUI 均未安装；workspace 依赖未装。spine-render.mjs 默认浏览器是 Windows Edge 路径，macOS 必须设 SPINE_RENDER_BROWSER。
